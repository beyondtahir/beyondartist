# Thumbnail packaging: research, hierarchy and vidIQ

Read for thumbnails/redesigns after intake and memory retrieval. This is shared procedural knowledge; category findings, a user's video title, private analytics and actual scorer output belong in that user's project memory. Use SYS-009/012/016 for type, attention and joint critique, SYS-024 for intake and SYS-025 for packaging. The designer interprets evidence; the artist remains free to invent within the actual brief.

## Official guidance checked 15 October 2026

vidIQ's design guide recommends a readily understood focal idea, brief legible lettering, clear value/color separation, suitable emotion and inspection at mobile display size. It treats title and overlay as complementary and warns against essential wording under the duration badge. Its suggested three-to-five-word overlay is a starting heuristic, not a universal requirement for every category, language or exact-copy brief. [vidIQ thumbnail design guide](https://vidiq.com/blog/post/youtube-thumbnail-design-tips/) (updated 14 July 2026; opened 15 October 2026).

vidIQ's June 2026 sample covers 500 breakout long-form videos across 30 niches. It reports faces in 69%, a five-word median among text-bearing thumbnails and exaggerated expressions in 5%. The article also recognizes object-led and text-free designs and says these associations cannot guarantee virality. Use this as bounded inspiration, not a causal rule or mandatory face/pose. [vidIQ thumbnail study](https://vidiq.com/research/youtube-thumbnail-study/) (updated 8 July 2026; opened 15 October 2026).

Optimize documentation describes feedback on emotional interest, legibility, composition, contrast, originality, subject/topic relationship and craft, plus previews in feed/search/mobile and light/dark contexts. Preview surroundings are illustrative; the score and preview cannot establish real performance. Its web draft-upload workflow does not prove that a particular MCP scoring tool supports unpublished work. [vidIQ Optimize](https://support.vidiq.com/en/articles/8972670-optimize) (dated 16 July 2026; opened 15 October 2026).

These paragraphs are source summaries. The workflow below is BeyondArtist's application of its existing design principles plus the checked guidance; no proprietary scoring formula or causality claim is inferred. ## Develop the title, image and visible words together

Confirm the video's actual topic, category, intended viewer and demonstrated payoff. If title is supplied, determine whether it is fixed or editable. If absent, retrieve relevant shared content/hierarchy/THUMB records, inspect relevant category examples where available, and draft a few original title–image–overlay pairs. Choose the pair that makes a clear relevant promise with an interesting visual consequence, comparison or emotion. Label generated title/copy as proposed. A working title can ground a thumbnail-only job without adding unrelated deliverables.

Research the requested category, not simply thumbnails with large reaction counts. Separate public guidance, actual inspected examples and private tool results. When using a vidIQ skill/tool, load its applicable current instructions and live schema rather than assume a stored command still works. Use public official vidIQ guidance to resolve general uncertainty without requiring a user account. If connected vidIQ evidence would materially improve a particular job and is authorized/available, use the appropriate focused capability. Do not require every user to install vidIQ, connect a channel or buy credits before BeyondArtist can create art.

Write the thumbnail's immediate promise and intended attention order before generation. A useful scheme is **dominant hook/subject → supporting consequence or expression → necessary topic/product cue**, but the order changes with the idea. No compulsory face-left/text-right grid, arrow, font or palette. Give each element a job; omit badges, logos or details without a purpose. Source library lessons and defining expressive craft still belong in the written handoff.

For visible text, specify exact words and punctuation, the key phrase, type voice, meaningful breaks, relative weight/scale, spacing, integration with the artwork and its contrast over the real background. Use the shortest copy that retains meaning; zero overlay words or a longer single clear phrase can be justified. Keep fixed wording intact, handle RTL shaping correctly, and let the title carry explanations that need not be printed in the image. Important content must survive the intended small display and UI overlays. Brand consistency can live in identity/type relationships without recycling every composition.

## Qualitative checks and actual scores

Before a vendor score, inspect the actual render. Record each relevant criterion as observed pass, repair needed or unverified, with the concrete finding. This checklist is BeyondArtist review, not a vidIQ numeric score:

| Check | Evidence to inspect |
| --- | --- |
| Content/promise | The image/title pair accurately represents what the video delivers; no invented benchmark, endorsement or urgency |
| Category/audience fit | Familiar recognition and an original response to the actual inspected sample or labeled offline hypothesis |
| Intended hierarchy | One readable leading idea, supporting elements with purpose, no unrelated highlight stealing emphasis |
| Visible typography | Exact wording, letterforms, line breaks and contrast remain clear at realistic display size |
| Subject/emotion | Recognizable required identity/product; expression or gesture supports the message without generic fake shock |
| Artistic execution | Coherent materials/marks/light and an authored concept; declared medium passes SYS-022 independently |
| Framing/interface | Essential content remains visible around duration overlays and relevant crops; inspect light/dark/feed context where practical |
| Final craft | Correct export, credible anatomy, clean spacing/edges and no distracting accidental collision |

If a real vidIQ scoring capability is available and within authorized scope/budget, it can add actionable critique. Inspect the current schema and inputs. The currently inspected `vidiq_score_thumbnail` MCP surface requires an image, intended title and real video ID; its documented score is 0–100. For unpublished work, the packaging skill requires a relevant own-channel proxy to be verified and disclosed before use. Do not invent a video ID or quietly use another person's unrelated video. A web product supporting drafts does not waive this MCP restriction. Tool signatures, access and prices can change; recheck them when calling.

If no valid context/access/budget exists, use the labeled qualitative checks and proceed with available art tools; don't fabricate a vendor score or make connection a creative blocker. Preserve any actual generation self-score separately from a separate scorer result. Actual score feedback can justify a focused revision but never overrides truth, identity, fixed copy, artistic medium or the intended audience. Don't repeatedly regenerate only to maximize points. Improve a concrete weakness, inspect again, and retain the best result for the brief. Publishing, channel changes and real A/B testing remain separate authorized actions.

## Save the useful evidence in project memory

Record the selected title, overlay copy, visual promise, intended hierarchy and source-to-decision lessons before rendering. Store official-guidance URLs with their review dates; category examples with actual inspection depth/metrics; and actual vidIQ output only when the tool ran. A `research` record can distinguish `public-vidiq-guidance`, `stored-guidance` or `connected-tool` in tags/data. A `decision` records our applied original choices rather than calling the reference a template.

For real score feedback store tool/provider, timestamp, exact title and image/asset ID, actual video/proxy identity and role, returned score/scale/kind, findings and accepted/rejected revisions. Keep account/private evidence in the owner-scoped store. Without scoring, explicitly set `scoring_status` to `not-run` and give the qualitative review source; no implied 100-point assessment. Save final full/small preview findings under actual artifact IDs so the next job can reuse relevant learning without rescoring unchanged material.

When browsing is unavailable, retrieve personal/project context and the shared THUMB/SYS/checked guidance records. Use stored principles and label dated inspiration honestly. Avoid unsupported current factual claims; do not label the offline concept a live trend. Audience outcomes remain unmeasured until supplied/authorized evidence exists; CTR must be interpreted with comparable impressions, traffic and content payoff, not a rubric number alone.
